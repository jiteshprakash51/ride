7 questions

Can I book a ride here?

No. This is a static information website, not a live booking service. There are no registered drivers, working bookings or passenger support offered here.

If internet is on, why can't phones do everything?

Internet access doesn't solve discovery, network barriers or app suspension. WebRTC still needs signaling, and some connections need relaying. Other participants could provide those roles, but someone must remain online.

Can the project stay completely free?

A constrained paid-service-free prototype is realistic using existing equipment and free allowances. A dependable public service still needs resources. There is no promise that it can cost everyone Rs 0 forever.

Who would pay the operating costs?

A cooperative, sponsor or donors could fund them without taking a cut of each fare. These are options only: there is no confirmed funder, partner or operating organization.

Is the app ready?

No. The app is a later stage. This website does not include an APK, live backend, live map or a release commitment.

Does the site use accounts or tracking?

The site has no account system, analytics, advertising, cookies or external API calls. Its demo inputs are processed only in this browser tab and are not submitted or stored. It does not request device location. A hosting provider may process ordinary request metadata under its own policies.

What about maps with no paid API?

A strict Rs 0 experiment can use manually entered pickup text or coordinates. Free map data is not the same as unrestricted free tile hosting. A production map and routing choice needs its own usage and policy review.
