# Contributing

Keep the app static, small and honest about its limits. Run `npm ci`, `npm run check`, `npm test`, `npm run build` and the documented browser tests before proposing changes. Preserve existing information pages and do not change unrelated infrastructure. Add tests for protocol transitions and treat all peer messages as untrusted input.

Do not add hosted discovery, telemetry, ads, maps, AI calls, payment services, blockchain, TURN credentials or other network dependencies without a design discussion and explicit owner approval. Never submit real rider/driver data or credentials. Contributions must be your own or carry a compatible license and attribution.
