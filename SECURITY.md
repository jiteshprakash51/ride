# Security

This is early test software, not audited transport infrastructure. Do not use for real passenger rides, payments, real identity documents or sensitive locations. Do not share connection codes publicly. Pair only with a known test partner and compare the fingerprint through a trusted channel.

Please do not post secrets, IP addresses, SDP connection codes, private journey data or exploit payloads containing other people's data in public issues. Use GitHub's private vulnerability reporting if enabled; otherwise open a minimal issue asking for a private reporting route, without sensitive details. No private reporting channel is promised yet.

No persistent secrets belong in this repository. Optional Cloudflare STUN requires no secret. TURN, blockchain, hosted relay, wallet and server-side database integrations are absent.
