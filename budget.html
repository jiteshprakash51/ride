Where the pilot money goes

Server + weekly image backups

DigitalOcean: $6/month for 1 GiB or $12 for 2 GiB; weekly backups add 20%. Test which size is sufficient. Images alone are not a complete database recovery plan.

Rs 1,100-2,200/month, approx.

Maps and routing

Potentially no API charge within selected allowances. Google's native Maps SDK lists unlimited free usage; Compute Routes Essentials and Geocoding each list 10,000 free events/month, then $5/1,000 at the first paid tier. Other APIs differ. API calls are not rides: ETA fan-out and refreshes multiply usage.
